# E-commerce Amazon - Frontend

Projeto de e-commerce inspirado na Amazon, desenvolvido como trabalho acadêmico. A aplicação permite que usuários naveguem por produtos, adicionem ao carrinho, finalizem pedidos e acompanhem seu histórico de compras. Administradores têm acesso a um painel para gerenciar produtos, usuários e vendas.

## Tecnologias utilizadas

- **Next.js 15** com App Router
- **React 19**
- **Zustand** para gerenciamento de estado global
- **TanStack Query** para data fetching
- **Axios** para comunicação com a API
- **Tailwind CSS** para estilização
- **React Hook Form + Zod** para formulários e validação
- **Back-end:** API REST em Java/Spring Boot hospedada no Railway

## Funcionalidades

- Autenticação: login, cadastro, recuperação de senha
- Listagem e busca de produtos
- Carrinho de compras
- Checkout e histórico de pedidos
- Perfil do usuário
- Painel administrativo (produtos, usuários, vendas)

## Como rodar localmente

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000) no navegador.
